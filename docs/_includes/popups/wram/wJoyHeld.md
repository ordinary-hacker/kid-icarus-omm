# wJoyHeld

**Address**: *C015*

## Description

This label's purpose is to store which inputs have been **held** / **kept pressed**.

Containing this type of data, it's accessed roughly *~40* times across the whole game for all sorts of purposes related to different actions tied to different inputs.

## Evidence

Hard evidence revealing that this label is for this purpose would be the function that populates it, **Game_PollInput**.

Please read it's entry, as it explains how it updates this value.
